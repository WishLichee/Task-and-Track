# Task & Track

一个简约美观的任务与日程管理网页应用，包含六大功能模块：

- **每周任务**：自定义任务并分配到一周中的某一天，按周一至周日纵向排列；完成后自动隐藏；已完成任务自创建起每满 7 天自动重新出现；无任务的周日期列表自动隐藏，全部无任务时显示空状态。
- **每日任务**：每天重复的待办事项，第二天自动重新填充，完成后隐藏，全部完成显示空状态。
- **定时刷新任务**：自定义任务在 N（1~365）天后自动重新出现，同一刷新天数的任务归入同一列表；支持完成、删除与查看任务列表。
- **长远任务**：持续时间 7 天起的长期目标，以浮动卡片呈现；剩余时间越多卡片越高（系数 0~1.5），卡片按两条轨道「累积高度较小者优先」排列；到期后标记为「已到期」；双击卡片可修改内容 / 持续时间或删除。
- **待办清单**：一个大的待办清单列表，可添加、完成与删除待办事项；完成后以「字体变淡 + 删除线从左到右 + 任务块整体消失」的动画收起。
- **选品集合**：候选商品列表，可新增 / 删除选品；每个选品记录闲鱼、小红书、天猫、抖音商城四个平台热度（带品牌色徽章）与进货价；「数据图」按钮打开该选品的五张折线图（曝光量 / 浏览量 / 点击量 / 成交量 / 售后量）。
- **数据图**：每张折线图支持单击新增点、点击已有点修改 / 删除、按数据自动缩放；双击进入查看模式（居中放大 1.2 倍 + 背景模糊 + 锁定），支持点击缩放、右键选择放大缩小、左右拖拽，再次双击确认退出。
- **日历视图**：完整月历，双击日期放大居中编辑当天事项（支持为每件事定义图标），单击日期展开 / 收回事项预览（移动端自动禁用展开）。
- **查看任务列表**：在每周任务 / 每日任务 / 定时刷新任务界面通过小按钮打开，任务分为「已完成 / 未完成」展示，支持直接删除。

## 运行方式

无需安装任何依赖、无需构建，直接用浏览器打开 `index.html` 即可。

```
双击 index.html（或用浏览器打开该文件）
```

## 技术说明

- 纯 HTML / CSS / JavaScript，无第三方依赖。
- 数据通过 `localStorage` 保存在本地浏览器中。
- 日期弹层采用 FLIP 动画实现「从日期格子放大移动至屏幕中央」，背景带轻微模糊效果。
- 完成任务时采用「字体变淡 + 删除线从左到右展开 + 任务块整体消失」的动画。
- 数据图为内联 SVG 折线图，查看模式采用 FLIP 动画 + `transform` 缩放拖拽实现。
- 移动端（≤768px）侧边栏自动变为底部栏，日历紧凑显示并去掉单击展开逻辑；选品集合 / 数据图模块按需求仅适配桌面端。
